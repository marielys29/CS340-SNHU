# CS340-SNHU Journal Reflection
## How do you write programs that are maintainable, readable, and adaptable?
Something I've learned from this course is that writing code isn't just about making sure everything works. It's also about making it easier to understand and work with later. I got to see this when I reused my CRUD Python module from Project One for the Grazioso Salvare dashboard in Project Two. Instead of starting everything from scratch, I already had a way to connect Python to MongoDB and retrieve the information I needed. This made things a lot easier because I could spend more time working on the dashboard itself. I also liked seeing how something I created for one assignment could become useful again in another. In the future, I could see myself using a similar module for other applications that need to store or retrieve information, especially since I wouldn't have to rewrite the same code every time.
## How do you approach a problem as a computer scientist?
I feel like my approach to programming problems has changed quite a bit since I started my computer science degree. Before, I was mostly focused on following the instructions and getting my code to work. With this project, I had to think more about what Grazioso Salvare actually needed and how I could make the information easier for someone to use. I worked on connecting the database, setting up the rescue filters, and making sure the table, chart, and map displayed the correct information. I remember having trouble with the map because it wasn't showing up, even though the other parts were working. It was frustrating at first, but after checking different things, I realized the layout needed some adjustments. That experience reminded me that not every problem is caused by the code I first suspect. Moving forward, I want to keep working through problems one step at a time, testing things as I go instead of trying to fix everything at once.
## What do computer scientists do, and why does it matter?
I think one of the biggest things I've realized throughout my computer science courses is that there's a lot more to this field than just writing programs. Computer scientists also figure out how to solve problems and make everyday tasks easier through technology. For example, the dashboard I created for Grazioso Salvare gives the organization a way to look through animal shelter information without having to search through all the records manually. They can select different rescue categories and see the matching animals along with charts and location information. Even though this was a class project, I can see how something like this could be useful for an actual organization trying to save time and make better decisions. Since I'm interested in becoming a game developer or software developer, I think learning how to create something that people can actually use is just as important as knowing how to code. It's something I want to keep improving as I continue working toward my degree.
